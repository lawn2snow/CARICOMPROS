# Hidden Kingz - Caribbean Service Marketplace Platform

## 🌴 Welcome to Hidden Kingz

The Caribbean's premier service marketplace connecting verified professionals with customers across 8+ islands.

## 🚀 Quick Deploy to Netlify

1. Click the button below to deploy directly to Netlify:

[![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start/deploy?repository=https://github.com/hiddenkingz/platform)

Or deploy manually:

1. Download the ZIP file
2. Extract all files
3. Go to [Netlify](https://app.netlify.com)
4. Drag and drop the folder to deploy

## 📂 Project Structure

```
hidden-kingz-platform/
├── index.html          # Main marketplace homepage
├── dashboard.html      # Contractor dashboard
├── admin.html          # Admin panel
├── manifest.json       # PWA configuration
├── sw.js              # Service worker for offline support
├── netlify.toml       # Netlify configuration
├── _redirects         # URL routing rules
├── robots.txt         # SEO configuration
├── sitemap.xml        # SEO sitemap
├── package.json       # Project metadata
└── README.md          # This file
```
